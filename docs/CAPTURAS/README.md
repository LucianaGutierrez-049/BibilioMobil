# Capturas requeridas

Pendientes de generar con la aplicación compilada en un emulador o dispositivo:

- Inicio claro
- Inicio oscuro
- Libros: Cargando
- Libros: Sin libros
- Libros: Con libros
- Libros: Error
- Lectores con teléfono ausente
- Préstamos

No se mantienen cambios temporales en los repositorios para provocar estados.
