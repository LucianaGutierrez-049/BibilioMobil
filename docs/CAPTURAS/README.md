# Capturas requeridas

Evidencias generadas con la aplicación Android compilada y ejecutada en un emulador:

- `Inicio_claro.png`: pantalla de inicio con tema claro.
- `Inicio_oscuro.png`: pantalla de inicio con tema oscuro.
- `Libros_Cargando.png`: catálogo durante la carga.
- `Libros_Sin_libros.png`: catálogo vacío.
- `Libros_Con_libros.png`: catálogo después de registrar un libro.
- `Libros_Error.png`: estado de error con opción de reintento.
- `Lectores_telefono_ausente.png`: lector registrado sin teléfono, mostrado como "No registrado".
- `Prestamos.png`: módulo de préstamos en construcción.

Para las capturas de carga y error se utilizó temporalmente la simulación permitida por el enunciado. Ese cambio fue retirado inmediatamente después: el repositorio final conserva la latencia aleatoria de 300 a 800 ms y su comportamiento normal en memoria.
